AL-thmany 2.0.0 — Adaptive Recovery Core

تطوير جذري للاستمرارية: cadence تكيفي event-first، تعافٍ من فقدان Accessibility root والشاشات الخاملة، حفظ التشغيل عند انقطاع الخدمة المؤقت، وتحقق أقوى بعد Join/Request قبل الانتقال. حد التشغيل الصريح بقي 150 رابطًا، والتقييد الحقيقي من واتساب يبقى توقفًا إلزاميًا.
كما أضيف Screen/Lock Guard لمنع استهلاك الروابط عند غياب Accessibility tree بسبب إطفاء/قفل الشاشة.
