# المساهمة في المشروع

شكرًا لمساهمتك. الهدف هو تطوير مدير روابط مجموعات بسيط، محلي، وآمن دون قراءة شاشة واتساب أو الضغط التلقائي داخل تطبيقات أخرى.

## قبل فتح Pull Request

1. أنشئ فرعًا باسم واضح، مثل `feature/import-json` أو `fix/parser-duplicates`.
2. نفّذ التعديل مع الحفاظ على حد عشرين رابطًا لكل جلسة.
3. أضف أو حدّث اختبارات الوحدة للمنطق الجديد.
4. شغّل اختبارات المشروع وبناء نسخة Debug.
5. لا ترفع ملفات APK أو مفاتيح توقيع أو `local.properties`.

## معايير الكود

- Kotlin واضح ومقسّم إلى دوال صغيرة.
- جميع النصوص الظاهرة للمستخدم داخل `strings.xml`.
- دعم العربية RTL والإنجليزية.
- عدم إضافة صلاحيات حساسة دون مبرر موثق.
- عدم إضافة Accessibility Service أو أي ضغط تلقائي داخل واتساب.
- عدم تخزين روابط المستخدم خارج مساحة التطبيق أو إرسالها إلى خادم.

## Pull Request جيد

يشرح المشكلة، والحل، وطريقة الاختبار، ويرفق صورًا عند تغيير الواجهة. اجعل كل Pull Request مركزًا على تغيير واحد قدر الإمكان.
