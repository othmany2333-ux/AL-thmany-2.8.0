AL-thmany 2.3.2 — Profile Accessibility Fix

الإصدار:
- versionCode = 232
- versionName = 2.3.2

الهدف العملي:
- معالجة حالة Work Profile / Samsung isolated profile التي ينجح فيها فتح أول رابط داخل واتساب لكن لا يوجد ضغط Join/Request بسبب عدم اتصال Accessibility داخل نفس Android profile.

التغييرات التي تم التحقق منها:
- Profile-local Accessibility heartbeat مستقل لكل Android user/profile.
- عدم اعتبار system-enabled وحده كافيًا لبدء Accessibility automation.
- فتح صفحة تفاصيل خدمة AL-thmany المحددة عبر ComponentName مع fallback آمن للإعدادات العامة.
- Profile Control Diagnostic يعرض profileKey والاتصال المحلي وآخر package event وحالة UI tree بدون تخزين محادثات أو روابط أو أسماء أشخاص.
- إذا بقي rootInActiveWindow غير متاح داخل Work/Samsung isolated profile، تتوقف الجولة مع حفظ الرابط الحالي بدل استهلاكه بدون ضغط.
- مسار الشخصي يبقى محافظًا على سلوك الاسترداد السابق.
- شاشات WhatsApp Restriction / Retry later تبقى hard stop؛ لا يوجد تجاوز Knox/MDM أو سياسات النظام.
