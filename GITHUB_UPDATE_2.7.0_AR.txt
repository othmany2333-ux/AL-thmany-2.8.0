AL-thmany 2.7.0 — Adaptive 1000-Link Runtime

أبرز التطويرات:
- رفع الجولة الصريحة إلى 1000 رابط متسلسل، مع قائمة محلية حتى مليون رابط.
- تحكم موحد بسرعة الانتقال للشخصي وملف العمل والمجلد الآمن من 0 إلى 10 ثوانٍ بدقة 100ms.
- تسريع Accessibility بإيقاع Event-first: 14ms للأحداث، 36ms للشاشة الثابتة، و95ms للفحص الاحتياطي.
- تشغيل Shizuku الدائم السريع بصورة تكيفية، مع رجوع تلقائي إلى UIAutomator عند عدم دعم الجهاز.
- إثبات سريع بعد Join للحزمة وAndroid user ونشاط المحادثة؛ ثم فتح الرابط التالي مباشرة بلا Back وبلا UI dump إضافي.
- توسيع فهم نصوص ومعرّفات واتساب العربية والإنجليزية الحديثة.
- واجهة جديدة برأس teal متدرج وبطاقات بيضاء وتحكم سرعة وحالة تشغيل أوضح.
- تعزيز الأمان بقفل الحزمة والملف الدقيق، ومنع الضغط منخفض الثقة، والإبقاء على Restriction/Retry Later كتوقف إلزامي.

مهم: حد 1000 هو حد جولة التطبيق، ولا يعني تجاوز حدود واتساب. ابدأ باختبار رابط واحد على كل ملف Android قبل تشغيل قائمة كبيرة.
