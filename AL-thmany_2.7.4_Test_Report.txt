Implemented regression protections
----------------------------------
1. Explicit runs self-disable restored Shadow observation mode in both runtimes.
2. Accessibility positive actions use a real dispatchGesture first; the bounded retry uses
   node ACTION_CLICK and is not suppressed by the first attempt's idempotency record.
3. Shizuku positive semantic actions prefer direct input injection over node ACTION_CLICK.
4. If the exact-user WhatsApp activity is foreground but its semantic tree remains hidden,
   a screenshot detector accepts only a wide lower-screen WhatsApp-green control.
5. The visual detector rejects small floating buttons and wide non-green controls.
6. The visual input is retried once only if the same wide action remains visible.
7. Joined conversations and request/result sheets are closed before opening the next link.
8. Non-loading fast liveness is bounded at 1,000 ms; real Loading remains protected at 20 s.
